# Superpowers Core Directives

Whenever embarking on software development, planning, debugging, or execution, always check and apply the relevant Superpowers skills:

1. **Before writing plans or coding new features:** Use `brainstorming` to explore intent, alternatives, and architecture.
2. **When planning implementation:** Use `writing-plans` with test-driven, verifiable steps.
3. **When executing tasks:** Use `executing-plans` and maintain task tracking.
4. **When debugging bugs or errors:** Use `systematic-debugging` (Investigate, Hypothesize, Test, Fix). Never guess.
5. **When implementing logic:** Follow `test-driven-development` (write failing test first, make it pass, refactor).
6. **Before declaring completion:** Use `verification-before-completion` to verify all tests and evidence.

Skills are located in `.agents/skills/` and globally in `~/.gemini/config/skills/`.
